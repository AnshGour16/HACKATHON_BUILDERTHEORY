# HireSphere AI - Flutter Mobile Application

Official cross-platform mobile client for **HireSphere AI** (All-Industry Recruitment & Talent Intelligence Platform).

## Key Features
- **Executive YouKT SaaS Aesthetic:** Light slate canvas, crisp white metric surfaces, emerald score dials.
- **AI Candidate Matches Grid:** Real-time candidate evaluation scores, skill tags, and pipeline status.
- **Candidate Scorecard & Rubric Breakdown:** Circular radial progress indicator, multi-criteria breakdown (Inbound Marketing, Code Quality, Domain Skills).
- **Recruiter Copilot Assistant:** Interactive chat window for sourcing insights and interview scheduling.
- **RESTful API Integration:** Connects directly to HireSphere backend endpoints.

## How to Run in Android Studio
1. Open **Android Studio**.
2. Select **Open** and choose this `flutter_app` directory.
3. Android Studio will automatically resolve Gradle dependencies and load the project structure.
4. Click **Run (`Shift + F10`)** to launch on connected Android emulator or physical device.

## CLI Execution
```bash
flutter pub get
flutter run
```
